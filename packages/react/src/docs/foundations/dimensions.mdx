# Dimensions

Spacing, sizes, radii and border widths are one stable set, shared by every theme and mode. The values follow Tailwind v4's scales and are defined in `@reflection/tokens`.

## Units

- Spacing, sizes and radii are in **rem**; 1rem is **16px**, fixed. Figma and native platforms convert with `rem × 16`.
- In **px**: `spacing/px` (1px), border widths, `radius/full` (9999px) and shadow geometry.
- A decimal point in a name is written as a dash: `spacing/0-5` → `--spacing-0-5`. The Tailwind utility keeps the dot: `p-0.5`.

## Spacing

Step `n` is `n × 0.25rem`. Use it for padding, margin, gap and inset.

| Steps                                                                                                | Value                       | Variable        | Utilities                                |
| ---------------------------------------------------------------------------------------------------- | --------------------------- | --------------- | ---------------------------------------- |
| `px`                                                                                                 | 1px                         | `--spacing-px`  | `p-px`, `gap-px`                         |
| `0`, `0.5`, `1`, `1.5`, `2`, `2.5`, `3`, `3.5`, `4`, `4.5`, `5`                                      | `n × 0.25rem` (0 … 1.25rem) | `--spacing-<n>` | `p-<n>`, `m-<n>`, `gap-<n>`, `inset-<n>` |
| `6`, `7`, `8`, `9`, `10`, `11`, `12`                                                                 | 1.5rem … 3rem               | `--spacing-<n>` | same                                     |
| `14`, `16`, `20`, `24`, `28`, `32`, `36`, `40`, `44`, `48`, `52`, `56`, `60`, `64`, `72`, `80`, `96` | 3.5rem … 24rem              | `--spacing-<n>` | same                                     |

Only these 36 steps exist. Tailwind's multiplier is set to step 1 (`--spacing: var(--spacing-1)`), so `p-4` = `4 × 0.25rem` = 1rem.

## Size

`size/<n>` mirrors every spacing step with the same value (`--size-4: 1rem`): the same scale, named for width and height. In Tailwind, `size-4`, `w-10`, `h-8` and `max-w-50` come from the spacing multiplier; the `--size-*` variables and `size/*` tokens carry the values for other platforms and Figma.

Containers are named sizes for content widths: `max-w-md`, `w-xl`.

Library usage: controls and rows (Button, fields, Item, Nav Item, menu rows, Tag, Tooltip) use `rounded-md`; menus, popovers and select lists `rounded-lg`; cards, item lists, dialogs and toasts `rounded-xl`.

## Border width

| Width | Variable           | Utility    |
| ----- | ------------------ | ---------- |
| 0     | `--border-width-0` | `border-0` |
| 1px   | `--border-width-1` | `border`   |
| 2px   | `--border-width-2` | `border-2` |
| 4px   | `--border-width-4` | `border-4` |

Components use the 1px `border`. There are no ring-width tokens: focus is a shadow (see Elevation and focus).

## Tokens

| DTCG path                   | Unit             | CSS variable                                    |
| --------------------------- | ---------------- | ----------------------------------------------- |
| `spacing/<n>`               | rem (`px`: px)   | `--spacing-<n>`                                 |
| `size/<n>`                  | rem              | `--size-<n>`                                    |
| `size/<3xs…7xl>`            | rem              | `--size-<name>` → Tailwind `--container-<name>` |
| `radius/<name>`             | rem (`full`: px) | `--radius-<name>`                               |
| `border/width/<0\|1\|2\|4>` | px               | `--border-width-<n>`                            |

A DTCG dimension keeps value and unit: `{ "value": 0.375, "unit": "rem" }`. All dimension variables are on `:root`, not per mode.

In TypeScript, `@reflection/tokens` exports the scales as data — `SPACING_STEPS`, `CONTAINER_SIZES`, `RADII` (rem), `BORDER_WIDTHS` (px), `REM_BASE` (16) — plus `dimensionTokens()`, which returns every token with its canonical name and `{ value, unit }`, and `toPx(dimension)` for platforms that work in px or pt.
