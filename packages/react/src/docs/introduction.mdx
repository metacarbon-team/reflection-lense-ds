# Reflection Lense

React 19 components on the Reflection Lense theme. Styling is Tailwind v4 utilities on the theme that Style Dictionary builds from the DTCG export of <a href="/" target="_top">Theme Lab</a>. Complex behaviour (dialog, menus, select, tabs, switch) uses Radix primitives.

## Setup

```css
@import 'tailwindcss';
@import '@reflection/theme/theme.css';
@import '@reflection/theme/fonts.css';
@source '../node_modules/@reflection/react/dist';
```

Set `data-mode="light"` or `data-mode="dark"` on `<html>`, or on any subtree for a local mode. Portalled content (dialogs, menus, select options) renders in `<body>`, so set the mode on `<html>`.

## Using components

- `className` is merged with `cn` (`tailwind-merge` that knows the theme's text roles): a utility you pass replaces the component's utility for the same property.
- A component exports its `*Variants` when the call alone gives its look (`buttonVariants`, `badgeVariants`, `tabsTriggerVariants`…), for styling other elements the same way.
- Every part renders `data-slot="<part>"` for targeting in CSS.
- Form controls (Input, Textarea, SelectTrigger, Checkbox, Radio, Switch) take their id, description, invalid and disabled state from the surrounding `Field`.
- `asChild` on Button, IconButton, Card, Link and NavItem renders the only child with their styles.

Use the toolbar's **Mode** control to switch the color mode.
