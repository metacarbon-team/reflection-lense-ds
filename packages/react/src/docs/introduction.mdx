# Reflection Lense

React 19 components on the Reflection Lense theme. Styling is Tailwind v4 utilities on the theme that Style Dictionary builds from the DTCG export of <a href="/" target="_top">Theme Lab</a> (ADR 0032). Complex behaviour (dialog, menus, select, tabs, switch) uses Radix primitives.

## Setup

```css
@import 'tailwindcss';
@import '@reflection/theme/theme.css';
@import '@reflection/theme/fonts.css';
@source '../node_modules/@reflection/react/dist';
```

Set `data-mode="light"` or `data-mode="dark"` on `<html>`, or on any subtree for a local mode. Portalled content (dialogs, menus, select options) renders in `<body>`, so set the mode on `<html>`.

## Conventions

- Variants are `cva` functions exported next to each component (`buttonVariants`, `badgeVariants`…), for styling other elements the same way.
- `className` is merged with `cn` (`tailwind-merge` that knows the theme's text roles): a utility you pass replaces the component's utility for the same property.
- Every part renders `data-slot="<part>"` for targeting in CSS.
- Form controls (Input, Textarea, SelectTrigger) take their id, description, invalid and disabled state from the surrounding `Field`.
- `asChild` on Button, IconButton and Card renders the only child with their styles.

Use the toolbar's **Mode** control to switch the color mode.
