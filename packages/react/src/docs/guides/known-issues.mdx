# Known issues

Where the code does not yet do what the other pages describe, and what is planned. Fixing an item removes it from this page in the same change.

## Components

| Issue                                                                                                                                            | Where       | Effect                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ----------- | --------------------------------------------------------- |
| The pale ground of a hatched chart series is mixed in code, `color-mix(… 18%, white)`, after Figma's white film over the tone; no token holds it | `chart.tsx` | The ground is not themed: it stays light in the dark mode |

## Tokens and theme

| Issue                                                                                                                            | Where                    | Effect                                                                     |
| -------------------------------------------------------------------------------------------------------------------------------- | ------------------------ | -------------------------------------------------------------------------- |
| Motion has no tokens: durations (150ms, 200ms) and easing are Tailwind and animation-utility defaults written in `lib/motion.ts` | `lib/motion.ts`          | Motion cannot be tuned per theme. Figma does not model motion, by decision |
| Nothing checks that the committed export matches the code defaults                                                               | `reflection.tokens.json` | Defaults and the shipped theme can drift apart                             |

## Generator and validator

| Issue                                                                                                                                                                                                                                                                                                                                                                           | Where                        | Effect                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Nothing validates the committed export: `pnpm theme` builds without validating, there is no CI, and Theme Lab exports a theme that fails rules. The current export passes every rule                                                                                                                                                                                            | `build.ts`, Theme Lab        | A theme with violations can ship                                                                                    |
| `bg/<role>` against `bg/<role>/emphasized` is not checked by the generator or the validator. Default accent ΔL 0.043; a pale accent (`#f0f0a0`) gives 0.028, under `layerStep`                                                                                                                                                                                                  | `generate.ts`, `validate.ts` | The tint and the solid fill of a pale role can read as the same                                                     |
| Palette step numbers do not order lightness: every token color is a step of its family's ramp, and the steps are not sorted by lightness. In light mode the accent fill, step 500 (L 0.93), is lighter than step 350 (L 0.85); status and neutral ramps break the order the same way, in both modes                                                                             | `palette.ts`                 | In the Figma Palette collection a higher step is not reliably darker (light mode) or lighter (dark mode)            |
| Coverage gaps that today's themes pass: the validator does not check `fg/neutral` on tints and status cards (the generator solves it, worst 5.13:1); neither measures ghost fills over `card/neutral/emphasized`, the menu rows (pressed and active clear `stateStep` by 0.003–0.005); the grammar accepts `bg/<status>/subtle` and `<scope>/<role>/on-emphasized` outside `fg` | `generate.ts`, `validate.ts` | Other seeds or a hand-edited payload can pass with a broken menu row, unreadable text or a name outside the grammar |

## Future improvements

| Improvement                                                                                                                | Why                                            |
| -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| CSS scoped by `[data-theme]` as well as `[data-mode]`                                                                      | Several themes on one page                     |
| TypeScript constants and a union type of token names                                                                       | Typed token names in code and tests            |
| Portable test vectors: fixed seeds → expected tokens                                                                       | Any port of the generator can prove it matches |
| Validate the export in `pnpm theme` and in CI                                                                              | Violations fail the build instead of shipping  |
| Figma sync keyed by a stable variable id in `$extensions`, with deprecation instead of deletion and a periodic drift check | Idempotent sync, safe renames, no silent drift |
| A JSON Schema for the native payload                                                                                       | Validation on native platforms                 |
